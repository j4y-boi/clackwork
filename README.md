# clackwork
The alarm clock with a built in macropad mode! 

## About:
This project was built for [Hack Club Blare](https://blare.hackclub.com/index.html), I got the idea to add a macropad mode after seeing the microcontroller that we were supposed to use. It reminded me a lot of the RP2040-based microcontroller I used to build a macropad before and after some research I found out that the MCU we use supported Bluetooth. So, now you got an alarm clock that wakes you up, but you can also use it to game, which will probably keep you awake.
